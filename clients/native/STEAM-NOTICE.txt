Steamworks.NET.dll and Valve's steam_api64.dll come from that official release.
steam_api64.dll is Valve's Steamworks redistributable, not covered by the wrapper's
MIT license. Steam and Steamworks are trademarks of Valve Corporation.

Spacewar AppID 480 is used only for development testing. This is not an official
Steam store release. A production Steam release requires the developer's own
assigned AppID and compliance with the Steamworks SDK terms.

Friends-only 2/4-seat rooms and public 1v1 Quick Match queues are supported.
Steam lobby metadata isolates Little Kingdoms protocol 2 from other AppID 480
test applications. Gameplay uses reliable ISteamNetworkingMessages packets on
channel 27109; Steam chooses the network route and may use Steam Datagram Relay.
This build does not promise that every route is relayed or that the overlay works
with WebView2. Manual lobby ID joining does not depend on the overlay.

Official documentation:
https://partner.steamgames.com/doc/sdk/api/example
https://partner.steamgames.com/doc/api/ISteamNetworkingMessages
https://partner.steamgames.com/doc/features/multiplayer/matchmaking

Windows users need their own signed-in Steam account. The game accesses Steam
identity, lobby membership, friends and game packets through the running client.
It never asks for a Steam password or embeds a Steam web API key. Steam test games
are peer-hosted and casual; they are not trusted for server-verified rankings.
